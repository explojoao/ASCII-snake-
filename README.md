# ASCII Snake 🐍

A classic Snake game recreated entirely with ASCII art — including the game itself and the JavaScript source code.

## 🎮 Play

[▶️ Play ASCII Snake](./index.html)

## 🕹️ Controls

- **Arrow Keys** — Move the snake
- **Touch / Swipe** — Move on mobile devices

## ✨ Features

- Classic Snake gameplay
- Entire game rendered using ASCII characters
- ASCII-styled JavaScript source code
- Keyboard controls
- Touch controls for mobile
- Score counter
- Collision detection
- Random food placement

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 💡 Inspiration

The idea was inspired by projects where the source code itself is arranged as visual art.

Instead of only making the game look like ASCII art, I wanted the **code itself to become part of the artwork**.
